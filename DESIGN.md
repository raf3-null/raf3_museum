# Approved direction: 3D collection cabinet
User approved a matte black cabinet in a white room, containing all 10 product photographs. CSS perspective and preserve-3d create real depth for cabinet sides, compartment floors and plinths. Product photographs remain flat, full-color planes; no claim of rotatable product models. Favorite Viper V4 Pro has the largest compartment. Pointer motion is subtle, disabled for coarse pointers and reduced-motion users, and has an explicit off switch. Native dialog provides protected inspection focus, Escape close and previous/next navigation. List view and category filters remain available. On mobile the cabinet faces forward with larger tappable compartments and a bottom inspection sheet. Buildless static root files remain ready for Vercel.
