# Dark 360° cabinet
User requested a black theme and a true model that rotates all the way around. Three.js provides solid closed sides/back, shelf geometry, plinths, lights and front-only product photograph planes. OrbitControls supports drag/swipe, wheel/pinch zoom and unrestricted azimuth. Explicit front/right/back/left controls, keyboard rotation and zoom, an HTML product selector and list view provide alternatives. A front raycast respects solid cabinet occlusion; dragging never opens a product. Camera presets respect reduced motion. WebGL failure switches to the list. Vendor modules are self-hosted and Vercel remains buildless.
